# Concurrency

**Package:** `SystemX.Infrastructure.Persistence.EfCore`
**Namespace:** `SystemX.Infrastructure.Persistence.EfCore`

## What it is
Optimistic concurrency management providing entity markers and automatic translation of EF Core concurrency collisions into `SystemX.SharedKernel.Concurrency.ConcurrencyException`.

## When to use it
- Use `IHasConcurrencyStamp` when optimistic locking is needed across HTTP APIs via headers (ETags, `If-Match`).
- Use `IHasVersion` when a simple integer/long incremented version column is preferred across providers.
- Use `IHasRowVersion` for database-generated byte-array rowversion timestamps (SQL Server `rowversion` / PostgreSQL `xmin`).
- Do NOT catch `DbUpdateConcurrencyException` in application handlers; let `SystemXDbContext` translate it into `ConcurrencyException`.

## How to use it
Implement one of the concurrency markers on your aggregate root. `SystemXDbContext` automatically configures concurrency tokens during model creation and checks them during `SaveChangesAsync`.

## EF Core Mapping by Marker
- `IHasConcurrencyStamp`: Configured as an EF Core concurrency token with `HasMaxLength(64)`. Automatically renewed with a new GUID string on every insert and update.
- `IHasVersion`: Configured as an EF Core concurrency token. Automatically incremented on every update.
- `IHasRowVersion`: Configured via `.IsRowVersion()`. Updated automatically by the database engine upon write.

## Provider Specifics
- **SQL Server:** Native `rowversion` / `timestamp` columns map directly to `IHasRowVersion`.
- **PostgreSQL:** PostgreSQL system column `xmin` will be natively mapped in `SystemX.Infrastructure.Persistence.Postgresql`.

## How `ConcurrencyException` Reaches the API
When an update conflicts with another concurrent modification, EF Core throws `DbUpdateConcurrencyException`. The `SystemXDbContext` save pipeline catches it, extracts the entity type and primary key, and rethrows a domain-friendly `ConcurrencyException(entityType, entityId, innerException)`. The Web pipeline middleware (`SystemX.Infrastructure.Web`) intercepts `ConcurrencyException` and automatically serializes an HTTP 409 Conflict ProblemDetails response.

## Sample code

### Using `IHasConcurrencyStamp` on an Aggregate Root

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;
using SystemX.Application.Abstractions.Persistence;
using SystemX.SharedKernel.Concurrency;
using SystemX.SharedKernel.Domain;
using SystemX.SharedKernel.Identifiers;

namespace ApplicationSample;

public sealed record ProductId(Guid Value) : GuidId(Value), IGuidIdFactory<ProductId>
{
    public static ProductId Create(Guid value) => new(value);
}

public class Product : AggregateRoot<ProductId>, IHasConcurrencyStamp
{
    public Product(ProductId id, string name, decimal price) : base(id)
    {
        Name = name;
        Price = price;
    }

    public string Name { get; private set; }
    public decimal Price { get; private set; }
    public string ConcurrencyStamp { get; private set; } = Guid.NewGuid().ToString("N");

    public void RenewConcurrencyStamp() => ConcurrencyStamp = Guid.NewGuid().ToString("N");

    public void UpdatePrice(decimal newPrice) => Price = newPrice;
}

public sealed class UpdateProductPriceHandler
{
    private readonly IRepository<Product, ProductId> _repository;
    private readonly IUnitOfWork _unitOfWork;

    public UpdateProductPriceHandler(IRepository<Product, ProductId> repository, IUnitOfWork unitOfWork)
    {
        _repository = repository;
        _unitOfWork = unitOfWork;
    }

    public async Task HandleAsync(ProductId id, decimal newPrice, CancellationToken cancellationToken)
    {
        var product = await _repository.GetByIdAsync(id, cancellationToken);
        if (product is null)
        {
            throw new InvalidOperationException($"Product {id} not found.");
        }

        product.UpdatePrice(newPrice);
        _repository.Update(product);

        // If another transaction renewed the ConcurrencyStamp, SaveChangesAsync throws ConcurrencyException
        await _unitOfWork.SaveChangesAsync(cancellationToken);
    }
}
```

## Configuration (if any)
No options required; markers are evaluated automatically by model conventions and save conventions.
