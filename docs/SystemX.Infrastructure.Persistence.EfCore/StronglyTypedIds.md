# StronglyTypedIds

**Package:** `SystemX.Infrastructure.Persistence.EfCore`
**Namespace:** `SystemX.Infrastructure.Persistence.EfCore.Configuration`

## What it is
Automatic discovery, mapping, and conversion of strongly-typed identifiers (`GuidId`, `IntId`, `LongId`, `StringId`) to primitive database columns without manual EF Core configuration.

## When to use it
- Use strongly-typed IDs across all aggregate roots and entity relationships to achieve compile-time type safety and prevent argument transpositions.
- Do NOT configure custom `HasConversion` for standard SystemX ID types; `StronglyTypedIdConvention` wires them automatically.

## Installation
`dotnet add package SystemX.Infrastructure.Persistence.EfCore`

## How to use it
Define strongly-typed IDs in your domain layer using records deriving from `GuidId`, `IntId`, `LongId`, or `StringId` and implementing the matching factory interface (`IGuidIdFactory<T>`, `IIntIdFactory<T>`, `ILongIdFactory<T>`, or `IStringIdFactory<T>`).

`SystemXDbContext` discovers these properties via `StronglyTypedIdConvention` during convention building and attaches the appropriate cached `ValueConverter`.

## Primary Key Generation Semantics
- **Guid and String IDs:** Configured automatically as `ValueGenerated.Never`. Guid and string identifiers are generated by the domain (client-side or application-side) prior to insertion, ensuring deterministic IDs before saving.
- **Int and Long IDs (Known Limitation):** Int and long IDs retain standard database identity auto-increment generation. However, because `IntId` and `LongId` guard against values `<= 0`, entities using auto-increment integer keys must be created with valid placeholders or parameterless constructors for ORM materialization.

## Sample code

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;
using Microsoft.EntityFrameworkCore;
using SystemX.Application.Abstractions.Persistence;
using SystemX.Infrastructure.Persistence.EfCore.Context;
using SystemX.SharedKernel.Domain;
using SystemX.SharedKernel.Identifiers;

namespace DomainSample;

public sealed record CustomerId(Guid Value) : GuidId(Value), IGuidIdFactory<CustomerId>
{
    public static CustomerId Create(Guid value) => new(value);
    public static CustomerId New() => new(Guid.NewGuid());
}

public class Customer : AggregateRoot<CustomerId>
{
    public Customer(CustomerId id, string name) : base(id) => Name = name;
    private Customer() : base(CustomerId.New()) { }

    public string Name { get; private set; } = string.Empty;
}

public sealed class StoreDbContext : SystemXDbContext
{
    public StoreDbContext(
        DbContextOptions<StoreDbContext> options,
        SystemXDbContextDependencies<StoreDbContext> dependencies)
        : base(options, dependencies) { }

    public DbSet<Customer> Customers => Set<Customer>();

    protected override void ConfigureModel(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Customer>(b =>
        {
            b.HasKey(c => c.Id); // Automatically converted to Guid and ValueGenerated.Never
        });
    }
}
```

## Configuration (if any)
No options required; conventions run automatically in `ConfigureConventions`.
